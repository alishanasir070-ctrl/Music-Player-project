# 🎵 Modern Web Audio Player

A clean, responsive, and customizable web-based audio player featuring a modern **Glassmorphism UI** aesthetic. Built with vanilla HTML, CSS, and JavaScript, this web application provides playback controls, dynamic playlist navigation, and responsive layouts for desktop and mobile viewports.

---

## ✨ Features

- 🎨 **Glassmorphism UI:** Translucent cards, backdrop blur filters, and accent colors.
- ⏯️ **Playback Controls:** Play, pause, seek progress slider, track skip, and volume adjustment.
- 📋 **Dynamic Playlist:** Interactive track switching with active state indicators and genre badges.
- 📱 **Responsive Design:** Grid layout optimized for mobile, tablet, and desktop screens.
- ⚡ **Zero Dependencies:** Built entirely with native HTML5, CSS3, and Vanilla JavaScript.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structural markup and audio elements.
- **CSS3:** Custom properties (variables), Flexbox, CSS Grid, and backdrop blur filters.
- **JavaScript (ES6):** DOM manipulation, audio event listeners, and playback logic.
